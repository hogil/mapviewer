# 피라미드 썸네일 생성 워크플로우 비교표

## 전체 프로세스 비교

| 단계 | 개인색 설정 **활성화** | 개인색 설정 **비활성화** |
|------|----------------------|----------------------|
| **1. 클라이언트 요청** | `?path=...&level=1.0&personalized=true&scheme=change` | `?path=...&level=1.0` |
| **2. 서버 경로 결정** | `pyramid_change_100/` | `pyramid_100/` |
| **3. 캐시 확인** | `pyramid_change_100/` 경로만 확인<br>비개인색 캐시 무시 | `pyramid_100/` 경로만 확인<br>개인색 캐시 무시 |
| **4. 레벨 1.0 생성** | 원본 PNG 로드 → 팔레트 교체 → 저장 | 원본 이미지 로드 → 저장 |
| **5. 다른 레벨 생성** | 레벨 1.0 파일 기반 리사이즈 | 원본 이미지 기반 리사이즈 |
| **6. Background 처리** | 개인색 적용된 이미지 사용 | 원본 이미지 사용 |

---

## 단계별 상세 비교

### 1단계: 클라이언트 요청 파라미터

| 항목 | 개인색 활성화 | 개인색 비활성화 |
|------|--------------|----------------|
| **URL 예시** | `/api/image?path=wafer/001.png&level=1.0&personalized=true&scheme=change` | `/api/image?path=wafer/001.png&level=1.0` |
| **personalized** | `true` | 없음 (또는 `false`) |
| **scheme** | `change` (또는 사용자 스킴) | 없음 |
| **캐시 버스팅** | `&_t=1234567890` (체크박스 변경 시) | 없음 |

### 2단계: 서버 경로 생성

| 레벨 | 개인색 활성화 | 개인색 비활성화 |
|------|--------------|----------------|
| **1.0** | `pyramid_change_100/wafer001_L100.webp` | `pyramid_100/wafer001_L100.webp` |
| **0.7** | `pyramid_change_70/wafer001_L70.webp` | `pyramid_70/wafer001_L70.webp` |
| **0.5** | `pyramid_change_50/wafer001_L50.webp` | `pyramid_50/wafer001_L50.webp` |
| **0.2** | `pyramid_change_20/wafer001_L20.webp` | `pyramid_20/wafer001_L20.webp` |

### 3단계: 캐시 확인 로직

| 조건 | 개인색 활성화 | 개인색 비활성화 |
|------|--------------|----------------|
| **확인 경로** | `pyramid_{scheme}_{level}/` | `pyramid_{level}/` |
| **무시 경로** | `pyramid_{level}/` (비개인색) | `pyramid_{scheme}_{level}/` (개인색) |
| **캐시 히트 조건** | 파일 존재 + 크기 > 0 + 수정시간 >= 원본 | 동일 |
| **캐시 분리** | 완전 분리 (서로 다른 디렉토리) | 기본 경로만 사용 |

### 4단계: 레벨 1.0 생성 프로세스

| 단계 | 개인색 활성화 | 개인색 비활성화 |
|------|--------------|----------------|
| **1. 이미지 로드** | PIL로 PNG 로드 (팔레트 모드 유지) | pyvips로 이미지 로드 |
| **2. 모드 변환** | 팔레트 모드(P)로 변환 (필요시) | 없음 |
| **3. 색상 적용** | 색상 스킴 로드 → 팔레트 교체 | 없음 |
| **4. 변환** | PIL → RGB → numpy → pyvips Image | 원본 그대로 |
| **5. 리사이즈** | 없음 (원본 크기 유지) | 없음 (원본 크기 유지) |
| **6. 저장** | `pyramid_change_100/` | `pyramid_100/` |
| **처리 시간** | 느림 (팔레트 교체 오버헤드) | 빠름 |

### 5단계: 다른 레벨 생성 프로세스 (0.7, 0.5, 0.2)

| 단계 | 개인색 활성화 | 개인색 비활성화 |
|------|--------------|----------------|
| **1. 소스 이미지** | 레벨 1.0 파일 우선 확인 | 원본 이미지 직접 사용 |
| **1-1. 레벨 1.0 존재** | 레벨 1.0 파일 로드 (pyvips) | N/A |
| **1-2. 레벨 1.0 없음** | 원본 이미지 로드 (pyvips) | N/A |
| **2. 리사이즈** | 레벨에 맞게 리사이즈 (예: 0.7 = 70%) | 레벨에 맞게 리사이즈 |
| **2-1. 큰 축소 (< 0.5)** | shrink + resize 조합 | shrink + resize 조합 |
| **2-2. 작은 축소 (≥ 0.5)** | resize만 사용 | resize만 사용 |
| **3. 저장** | `pyramid_change_{level}/` | `pyramid_{level}/` |
| **처리 시간** | 빠름 (레벨 1.0 기반이면) | 보통 |

### 6단계: Background 처리

| 항목 | 개인색 활성화 | 개인색 비활성화 |
|------|--------------|----------------|
| **실행 시점** | 현재 레벨 생성 완료 후 | 동일 |
| **처리 레벨** | 현재 레벨 제외, 1.0 제외 | 동일 |
| **소스 이미지** | 원본 PNG → 팔레트 교체 → RGB 변환 | 원본 이미지 |
| **파이프라인** | 한 번 로드한 이미지로 여러 레벨 생성 | 동일 |
| **동시성** | ThreadPoolExecutor로 병렬 처리 | 동일 |

## 클라이언트 캐시 비교

| 항목 | 개인색 활성화 | 개인색 비활성화 |
|------|--------------|----------------|
| **캐시 키 형식** | `{level}_p_{scheme}` | `{level}_n_change` |
| **예시** | `0.7_p_change` | `0.7_n_change` |
| **캐시 무효화** | 체크박스 변경 시 `_personalizedColorCacheBuster` | 없음 |
| **브라우저 캐시** | `no-cache` 헤더 (캐시 버스팅 시) | `max-age=31536000` |

```
│   ├── wafer001_L70.webp   (레벨 1.0 기반 리사이즈)
│   └── wafer002_L70.webp

│   └── ...
└── pyramid_change_20/
    └── ...
```

```
THUMBNAIL_DIR/

│   └── wafer002_L100.webp
├── pyramid_70/
│   ├── wafer001_L70.webp   (원본 기반 리사이즈)
│   └── wafer002_L70.webp

│   └── ...
```

## 성능 비교

| 항목 | 개인색 활성화 | 개인색 비활성화 | 비고 |
|------|--------------|----------------|------|
| **레벨 1.0 생성** | 느림 (~500ms) | 빠름 (~100ms) | 팔레트 교체 오버헤드 |
| **다른 레벨 생성** | 빠름 (~50ms) | 보통 (~100ms) | 레벨 1.0 기반이면 빠름 |
| **메모리 사용** | 높음 (PIL + numpy + pyvips) | 낮음 (pyvips만) | 개인색 적용 시 메모리 증가 |
| **디스크 사용** | 2배 (개인색/비개인색 분리) | 1배 | 캐시 분리로 인한 증가 |

## 호출 시퀀스 비교

### 개인색 활성화 시
```
[사용자] 이미지 선택 + 개인색 체크박스 ON
    ↓
[클라이언트] GET /api/image?path=...&level=1.0&personalized=true&scheme=change
    ↓
[서버] 캐시 확인: pyramid_change_100/ 없음
    ↓
[서버] 원본 PNG 로드 → 팔레트 교체 → 저장 (pyramid_change_100/)
    ↓
[서버] 응답 반환
    ↓
[서버] Background: 다른 레벨 생성 (0.7, 0.5, 0.2)
    ├─ 원본 PNG → 팔레트 교체 → 레벨별 리사이즈
    └─ 저장: pyramid_change_70/, pyramid_change_50/, pyramid_change_20/
    ↓
[사용자] 줌 변경 → level=0.7 요청
    ↓
[서버] 캐시 확인: pyramid_change_70/ 존재
    ↓
[서버] 즉시 반환 (캐시 히트)
```

### 개인색 비활성화 시
```
[사용자] 이미지 선택 + 개인색 체크박스 OFF
    ↓
[클라이언트] GET /api/image?path=...&level=1.0
    ↓
[서버] 캐시 확인: pyramid_100/ 없음
    ↓
[서버] 원본 이미지 로드 → 저장 (pyramid_100/)
    ↓
[서버] 응답 반환
    ↓
[서버] Background: 다른 레벨 생성 (0.7, 0.5, 0.2)
    ├─ 원본 이미지 로드 → 레벨별 리사이즈
    └─ 저장: pyramid_70/, pyramid_50/, pyramid_20/
    ↓
[사용자] 줌 변경 → level=0.7 요청
    ↓
[서버] 캐시 확인: pyramid_70/ 존재
    ↓
[서버] 즉시 반환 (캐시 히트)
```

## 문제 해결 케이스 비교

| 문제 상황 | 개인색 활성화 | 개인색 비활성화 |
|----------|--------------|----------------|
| **레벨 1.0만 색상 적용됨** | 레벨 1.0 파일 기반 생성으로 해결 | 발생 안 함 |
| **일부 레벨만 색상 적용됨** | 캐시 키에 scheme 포함으로 해결 | 발생 안 함 |
| **캐시 혼선** | 경로 완전 분리로 해결 | 발생 안 함 |
| **레벨 1.0 파일 없을 때** | 원본 이미지 사용 (폴백) | 원본 이미지 사용 |
